정확한 제조사와 모델을 알면 알맞은 BIOS와 드라이버를 찾기 쉽습니다. 이 사이트는 자동으로 PC 사양을 읽지 않습니다.

1. 제조사와 시스템 모델 확인

2. 그래픽 카드(GPU) 모델 확인

Win + X → 장치 관리자를 열고 ‘디스플레이 어댑터’를 펼치세요.

자주 묻는 질문

‘To be filled by O.E.M’으로 나와요

조립 PC에서는 정보가 입력되지 않았을 수 있습니다. PC 케이스나 메인보드 기판의 모델명을 확인하고, 정확하지 않으면 제조사 지원 안내를 참고하세요.

노트북 BIOS 업데이트가 필수인가요?

설치 중 화면이 달라졌나요?

작업 중 문제가 생기면 무리하게 다음 단계로 넘어가지 말고, 아래 증상과 공식 지원 안내를 확인하세요.

● 일시적인 화면 변화는 드라이버 작업 중 나타날 수 있습니다.

다만 오랫동안 복구되지 않거나 오류가 반복되면 기기를 재시작하기 전에 오류 화면을 기록하고 제조사 지원을 확인하세요.

해상도가 800×600으로 바뀌었어요

가능한 원인 그래픽 드라이버 제거 뒤 Windows 기본 디스플레이 드라이버를 사용하는 중일 수 있습니다.

확인 방법 미리 받은 정식 드라이버를 실행해 설치를 완료한 뒤 해상도를 확인하세요.

낮은 해상도 상태가 계속되면 GPU 모델과 드라이버 호환성을 확인하세요.

설치 중 화면이 깜빡이거나 잠시 검게 보여요

가능한 원인 디스플레이 드라이버를 전환하는 동안 화면 신호가 잠시 끊길 수 있습니다.

확인 방법 잠시 기다리고, 설치 진행 상태가 보이면 완료될 때까지 기다리세요.

장시간 화면이 복구되지 않거나 오류가 보이면 강제 종료 전 공식 안내를 확인하세요.

DDU를 위한 안전 모드에 들어가고 싶어요

순서 Shift를 누른 채 다시 시작 → 문제 해결 → 고급 옵션 → 시작 설정 → 다시 시작 후 키보드 숫자 4를 선택합니다.

Windows 버전에 따라 메뉴 이름이 달라질 수 있습니다. 화면이 다르면 Microsoft 공식 안내를 확인하세요.

BIOS 업데이트 뒤 재부팅을 반복해요

가능한 원인 메모리 트레이닝 과정에서 재부팅이 반복될 수 있습니다. 보드와 메모리에 따라 동작은 다릅니다.

확인 방법 제조사 설명서에 안내된 대기 시간을 확인하세요. 업데이트 도중 전원을 끄지 마세요.

오래 지속되거나 오류 LED·경고음이 계속되면 보드의 공식 복구 절차를 확인하세요.

컴퓨터는 켜졌는데 모니터에 신호가 없어요

확인 방법 모니터 입력 소스와 케이블 연결을 확인하세요. 외장 그래픽 카드가 있다면 케이블이 그래픽 카드 포트에 연결됐는지 살펴보세요.

포트 위치와 복구 절차는 케이스·메인보드·그래픽 카드에 따라 다를 수 있습니다.

오류가 발생해 다음 단계로 갈 수 없어요

먼저 할 일 오류 문구를 기록하고, 작업을 반복하거나 임의 파일을 사용하지 마세요.

다음 확인 정확한 제품 모델의 공식 지원 페이지에서 오류 설명과 복구 절차를 확인하세요.
